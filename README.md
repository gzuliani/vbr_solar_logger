# VABIRA VBR-Solar Logger

Proof of concept of a data logger for the VABIRA VBR-Solar sensor.

The communication protocol has been deduced so there are no guarantees that the data collected will correspond exactly to the readings shown by the official app.

## Dependencies

- bleak
- platformdirs
- pyinstaller
